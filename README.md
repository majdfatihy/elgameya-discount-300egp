# ElGameya – دليل تطبيق الجمعية

دليل مستقل من إعداد ماجد فتحي، يجمع شروحات تطبيق الجمعية ElGameya وكود الدعوة `ujrcxa` ورابط الإحالة https://onelink.to/etm456.

يتضمن 22 فيديو من قناة ماجد فتحي وشروحات الاشتراك وسداد الأقساط والقبض ورسوم الأدوار والانسحاب.

قيمة الخصم 300 جنيه وفق العرض الذي أفاد به صاحب رابط الإحالة، ويجب التأكد منها ومن شروط الأهلية داخل التطبيق قبل الاشتراك.

الموقع الرسمي: https://elgameya.net/en/index.html

صفحات السياسات والتواصل موحدة في https://dev.majdfatihy.com/.

الفيديوهات التاريخية التي تذكر خصم 200 جنيه أو شروط عقد عام 2025 ليست مصدرًا لتأكيد العروض والشروط الحالية.
